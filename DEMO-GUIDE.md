# Assessment walkthrough

1. Open https://jdeiah55.github.io/discover-reading-room/ and choose **Try a demonstration library**. No downloads or API setup are needed for the main demonstration.
2. Under **Describe the feeling**, enter:

   > I want to be immersed in a dystopian world where everyone is fighting to survive, but the heroine has magic powers that no one knows about, except for a secret society that sent an assassin to kill her, but they fall in love instead.

3. Inspect a partial alternative's supported and unresolved conditions. Unresolved does not mean absent.
4. Start a **separate** structured search. Clear filters; select Mood **Whimsical**, Atmosphere **Circus**, Genre **Fantasy**, Trope **Magical competition**, Author **Erin Morgenstern**. Leave other fields unrestricted. **The Night Circus** has supporting recorded attributes in the demo.
5. Exclude that title from recommendations, then find it under **Explore your library**. Exclusion does not delete the entry. Restore eligibility if repeating the demonstration.
6. Optional: open library management, then **Give your books a little more detail**. Enrichment uses a separate free-host service and shared provider quota, so it may need time to wake up. A completed lookup can return no new automatic labels if suggestions lack sufficient support or duplicate existing information.

Changes affect only the visitor's browser. Back up an existing personal collection before replacing it. The import accepts book-list CSVs, not full book PDFs.
